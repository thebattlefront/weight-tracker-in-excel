# Weight Loss Tracking (2022–Present)

A personal data-tracking project documenting my weight loss journey from 2022 to the present, using historical weight records organized and analyzed in Microsoft Excel.

## Overview

A chronological record of weight measurements collected over several years, providing a historical view of weight changes and long-term progress.

## Tools & Skills

- Microsoft Excel
- Excel Pivot Tables
- Data organization and historical tracking

## Features

- Organized historical weight records
- Chronological tracking of weight measurements
- Historical data analysis using Excel Pivot Tables

## Purpose

To maintain an organized record of my weight over time and use historical data to monitor long-term progress.
